# 购买保障配置读取

2026-10-29，C01 局部交付。Gin `GET /api/store/buy-policies` 读取服务端绑定店铺的 `metadata.buy_policies`；Astro 正式商店页将结果交给原购买保障组件，中英、期限和备注的展示沿用原逻辑。没有 Medusa 运行依赖。

来源：`medusa-store/apps/backend/src/lib/buy-policies.ts`、公开 `store/buy-policies` 路由以及原前台 `lib/data/buy-policies.ts`。四项配置必须整体合法：保修 0—120 个月、退货 0—365 天，中英文备注各最多 200 个 UTF-16 单元并去除两端空白。根配置不接受额外字段；备注只公开 en/zh。缺失或配置不合法时整体沿用原默认值 24 个月/14 天，不写回数据库；显式零值仍表示不提供保修/不支持退货。

店铺缺失、数据库或元数据读取失败返回统一 503。接口拒绝任意查询参数；固定店铺、只读事务、元数据大小上限、显式公开投影及 no-store，不能由调用者切换店铺或获取其他 metadata。Astro 不转发来访 Cookie/Authorization，不跟随重定向；可选接口失败时保留原“详情请咨询客服”状态，不影响商品搜索或擅自使用默认承诺。

验证覆盖 Go 配置解析、真实隔离 MySQL 的绑定店铺/公开投影/默认值/零值/无写入，以及前台精确契约和浏览器中英展示、零值及可选接口失败。报告见 `gin-buy-policies-report.json`。

后台配置编辑尚未迁移；商品详情页的保障衔接及整个前台联合闭环继续执行，不以本接口代表全站完成。
