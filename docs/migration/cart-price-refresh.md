# 购物车行价格刷新阶段

2026-10-28，T032/T033 的中间实现，完整重算及结账未验收。

`cart.RefreshItemPrices` 参与调用者拥有的事务，再次锁定当前持有者、代次、购物车和所见版本。地区、币种和渠道来自锁定的购物车及服务器店铺配置，数量来自当前活动行，计算时间由服务器编排提供。函数不接受浏览器价格或选价规则。活动行最多1000，按行数量分组、同组变体去重后调用现有精确 `pricing.Read`；同一 SKU 出现在不同数量的行时，分别选阶梯价，不能合并成整车 SKU 总量选价。

已核对安装来源的 refresh-cart-items、get-variants-and-items-with-prices、get-variant-price-sets 及 prepare-line-item-data。非自定义、有变体的行必须获得当前价格；变体必须仍属于公开商品和当前渠道。自定义单价及无变体手工行保留精确 raw 价格与含税标志；自定义变体没有价集可保留价格，但不能绕过有效变体检查。Gin 目录还要求配置完整，沿用既有可购买性策略。未知条件和自定义选价 hook 未实现，不得推断其价格。

新单价保留超出18位小数的 raw，兼容 SQL 标量按已有策略截到18位；计算与显示使用精确 raw。已有划线价（包括0）保留其原标量与 raw，不因非 sale 或新原价而覆盖；仅缺失划线价且命中不等价 sale 时补原价。手工内容、数量、标题、metadata、库存和税/优惠行不由此价格阶段改写。原完整准备流程中的商品快照补全和礼品卡标志刷新仍需后续阶段承接。

先完成全部选价、检查及写入准备，再修改行。任何价格缺失、下架、存储或后续编排错误都要求调用者回滚整个事务。该组件不提交事务、不递增版本、不创建回执，不提供独立 HTTP 成功。地区变化时的自定义价格行移除，由前置上下文阶段负责；价格函数不能自行删除它们。最终编排必须统一完成上下文/地址、商品快照、库存校验、税/优惠/配送、版本与幂等回执后才能提交。

隔离实库用例见 identity/cart_price_refresh_test.go，实际结果以 admin-auth-report.json 的 cart_price_refresh 和源码摘要为准。覆盖同 SKU 两行不同数量、共享价集、21位 raw 小数、含税偏好、自定义与无价集/手工行、原划线价与 sale 回退、已删除行保留、后续失败及第二行写入失败回滚、下架/缺价拒绝、旧版本拒绝和保存地区选价。测试使用29个显式迁移及人工匿名购物车，不使用旧登录账号。
