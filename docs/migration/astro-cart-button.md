独立commerce-fixture由Astro SSR通过既有loadProduct读取自有Gin的正式可购商品；实际client:load水合包装和原按钮。该fixture不进入生产src/pages，也不伪装完整商城。后台/Vite及原组件回归结束后关闭前监听，fixture才使用同一允许Origin的19200端口；不改Gin Origin，也不占旧8000/9001。
