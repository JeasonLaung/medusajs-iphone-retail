# SKU 图片关联与原 iPhone 自动配图

2026-10-31：React Admin 商品详情每个 SKU 增加 Ant Design 图片抽屉，可从该商品图库选择/解除 SKU 图片，选择已关联图片为缩略图、保留已有独立缩略图或显式清空。上传新图沿用商品图片管理。保留原商品详情、SKU、价格及库存交互。

Gin `GET/POST /api/admin/products/:id/variants/:variant_id/images` 复用 0089 的默认关闭 `product.images` 能力、认证/Origin/CSRF、当前 `product.read` / `product.write` 权限和不可变图片操作收据，不新增 SQL 迁移。回执 SHA256 显式绑定命令类型、商品、SKU、员工和完整请求；同 UUID 不能跨 SKU 或跨图库命令重放。每次重放仍核对当前权限；关闭能力后仍可恢复已完成操作回执。

事务以 READ COMMITTED、当前商品/SKU 行锁串行保护图库和关联。只允许当前商品的未删除图片；重复 ID、未选择的缩略图、过期版本或跨商品 SKU/图片拒绝。更新采用关联记录软删除，保留原记录和图片身份；操作及最终回执失败会整体回滚。存在指向已删除/外商品图片或重复活动关联的异常历史时不自动清洗或丢弃，返回不可用供后续核对。

保留缩略图是显式选择；解除图库关联不会暗中清除独立缩略图。商品图库继续检查活动 SKU 图片关联和缩略图引用，必须解除关联并明确清空/更换缩略图后才能移除原商品图片，避免前台出现断图。

同时核对并补齐原 `medusa-store/apps/backend/src/lib/iphone-product-images.ts` 和 `src/subscribers/iphone-product-images.ts` 的新建 SKU 配图规则：按 `swappie-` 机型标识及 Color/Colour/颜色选项，匹配 `/iphone-products/<model>/<color>/<file>` 图片路径，保留 Product (RED) 颜色别名，按 URL 顺序选择图库及首张缩略图。该逻辑是现有 SKU 创建事务的一部分，和 SKU、选项、库存项、ERP 编号和最终回执共同提交或回滚；无匹配时不制造图片。手动图库能力默认关闭不改变原 SKU 创建配图语义。已有 SKU 的颜色/完整选项编辑尚未交付，相应更新联动需随该功能继续验证。

## 验证

使用完整 89 项迁移的独立本机 MySQL、受限测试用户、Redis 命名空间和独立 API/Admin/Astro 端口。主试运行库与源数据库未改变，没有真实支付、邮件或业务客户写入。

- 原生 MySQL：4 个相同请求只写一次；原缩略图保留；过期版本、跨商品图片/SKU、跨 SKU 重放拒绝；其他 SKU 不变；最终回执失败完整回滚；解除关联但保留缩略图仍阻止图片移除，明确清空后可移除；历史软删除保留；关闭开关恢复回执和撤权拒绝。
- 原生 SKU 创建：iPhone 机型/颜色自动匹配及首张缩略图正确、重复创建请求不复制图片关联；最终回执失败时 SKU、图片关系及库存全部回滚。该测试使用合成公开 URL，不发起远程图片请求。
