2026-10-30。承接原业务的照片审核、要求重拍、批准寄件、确认收货与收货前取消。React Admin 使用 Ant Design 列表、筛选、详情抽屉、私有照片预览、确认表单和历史时间线，复用原前台问卷的中英文答案标签；前台布局和交互保持原实现。

## 业务与权限

0077 增加默认关闭的 buyback_admin_runtime，授权模型新增 buyback.read/write（28 个动作）。旧角色不自动获得新授权，仓库角色不能获得平台回收操作范围。读写都在事务中重查当前授权；写入锁定申请再核对状态、最新照片与必需照片。要求重拍必须提供至少三个 UTF16 字符的说明；照片仅能审核当前版本。状态、照片审核、历史、审计及符合条件的新账号站内通知同事务，失败整体回滚。并发批准寄件只有一次成功。

GET /api/admin/buyback 支持固定 20 条分页、状态和关键字筛选；详情/命令/私有照片均经过现有 Admin 会话保护，POST 复用现有 CSRF。严格拒绝未知/重复查询参数、非法状态、非规范 offset、重复 JSON 键和跨店铺请求。照片复用已有私有图片内容读取，不暴露存储路径。

当前列表限于新账号显式归属的新申请。旧申请后台导入与归属处理尚未验收；不通过旧邮箱映射登录身份。后续检测关联与报价已承接，见 [设备与报价](gin-buyback-inspection.md)；打款和退回操作仍待完成。
