# Astro 正式首页

2026-10-29。C01 局部交付；全站未验收。

`/{countryCode}` 使用既有地区/语言、头尾和公开目录读取，通过独立 Gin 的直接 iPhone 子分类构造首页系列。按原固定顺序 17、Air、16、15、14、13、12、11、SE 展示已存在的系列，前三个构成轮播；没有根分类时保留原空目录状态。分类读取失败返回 503，未知地区/语言为 404。系列卡片和轮播进入原 `store?series=...` 链接；博客、文章与商品链接使用显式地区语言路径。

首页 gallery、carousel、rail、blog、reviews、Rating 及对应 CSS 来自原前台；原译文复用已有 journal 的原 home i18n。Next image/link 替换为已有原生图片和本地化链接，异步服务端读取集中在 Astro，轮播、键盘、横向滚动与响应式布局保留。14 张系列图片逐字节复制并验证，来源见 `astro-home-sources.json`。本次没有修改原 CSS 色值、间距或字体。`npm run test:home` 读取原组件正文与 CSS，用同一组人工数据在中英、390/768/1440 三宽、轮播初始/切换状态进行 12 次完整首页内容截图比较，结果逐字节一致；仅桥接 Next 图片/链接与异步数据，不代表真实目录整站验收。

评价区读取系列直接关联商品，跨系列商品去重，对每个商品取原公开评价页（最多 5 条），按日期倒序选最新 3 条。复用已有严格商品投影，关系分页与总量受限；公开请求不带 Cookie/Authorization，评价读取最多并行 4 个，全部目录/评价请求共享 8 秒超时边界。部分商品读取失败保留其他已读取评价，全部评价失败使用原“评价暂不可用”状态，无商品则使用原空评价状态。

**Gin 评价存储、导入、审核与公开接口尚未迁移**。当前真实 Gin 对评价请求返回不可用，正式首页显示对应原状态；浏览器人工公开 fixture 只验证评价卡片的显示和链接，不表示真实评价业务完成。独立评价页面及提交/审核按 C09 继续，不能据此声称评价闭环。

生产启动改为 `node scripts/start.mjs`（`npm start`）：在加载 Node SSR 依赖前固定 production 模式，使 Ant Design 的服务端样式标识与编译后的浏览器一致。原直接启动在未设置 NODE_ENV 时产生开发标识，导致已水合的 Rate 使用了错误选择器，出现竖排蓝色星形；生产入口修复后恢复原黄色横排。浏览器验证水合后的样式实际生效，未覆盖 CSS 或重写星级控件。原 Next AntdRegistry 的服务端样式提取尚需在 Astro 补齐，当前截图对照不覆盖禁用 JavaScript 时的 Ant 控件样式或加载前闪烁。

验证覆盖原系列顺序、轮播切换、系列导航到商店、移动横向滚动、博客/评价展示、所有首页图片解码、窄屏无溢出、空目录/评价失败及核心依赖失败。实际隔离 Gin 的首页验收使用无 iPhone 分类的人工目录，因此只证明真实依赖和空目录状态；真实导入数据与原站同数据截图对照仍待联合验收。执行结果见 `astro-runtime-report.json` 与 `astro-home-report.json`，查看源文件哈希是否匹配本次代码。
