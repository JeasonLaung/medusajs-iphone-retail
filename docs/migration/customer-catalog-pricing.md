# 登录客户的商品与搜索报价

补齐客户组管理后的商品展示链路，沿用原价格引擎、商品投影、筛选和界面。登录客户的商品详情、相关商品、集合页、商店搜索及规格/数量报价接口，从当前新账户明确的组成员关系计算；公开 Gin 商品和搜索接口继续匿名报价，即使请求携带客户 cookie 也不会返回组价格。

新增 `/api/store/customer/products`、`/products/:id` 和只读 `POST /search`，经过现有 Astro 签名桥接、Host/Origin、客户会话检查。客户和组 ID 均不接受浏览器指定。SQL 事务先锁定当前账户并重新核验会话版本，再锁定成员关系，然后建立商品/价格读取快照；schema 扩展检测使用当前读，避免在等待成员关系前提前建立旧快照。

Astro 通过请求内的 fetch 适配器复用原 typed loaders；只允许固定 Gin 目的地的商品和搜索请求进入客户桥接。不会修改全局 fetch，也不把客户身份传入地区、SEO、评论等公开读取。浏览器无需改变原商品或搜索 API 路径，搜索初始渲染和后续筛选都走当前账户价格。

私有报价和相应 Astro 页面返回 `private, no-store` 和 Cookie Vary，错误及 404 同样禁止公共缓存。明确的 401 过期会话回到匿名读取；503、传输和持久层异常继续报错，不静默降价。无新增 DDL。
