# 已有价目表的 SKU 成员价格录入

复用现有 SKU 价格抽屉及创建事务，增加“新增价目表价格”入口，选择已有价目表，再录入币种、精确金额、可选地区及包含端点的数量上下限。保留基础/地区/数量价格原入口和共享价格集合行为。价目表状态、生效时间及规则沿用既有公开报价选择；草稿、未来生效表可以配置成员，但不提前用于前台报价。

来源 `price-list-prices-add-form.tsx` 通过 `useBatchPriceListPrices` 的 `create` 参数增加表内价格。本批实现其中按 SKU 增加成员的能力；来源选择多个商品并一次性提交、完整价目表创建向导及来源批量替换仍需继续，不能据此认定完整价目表管理或 C03 完成。

Gin 沿用 `GET .../price-creation` 和 `POST .../prices`，增加可选字符串 `price_list_id`；省略时保持原基础价格命令。上下文返回未删除价目表的 ID、标题、状态和类型，私有版本纳入价目表设置及规则，选中表删除后拒绝写入及已完成收据重放。重复身份按价目表、币种、地区和数量上下限组合校验，不阻止基础价格与表内价格并存，也不禁止来源支持的重叠数量区间。上下文超过一千价目表/一万规则时拒绝，不静默截断。

沿用当前权限、默认关闭价格门禁、全局价格锁、预期版本和操作收据。单事务写入精确 scalar/raw 金额、可空数量及其 raw 镜像、price_list_id、地区规则、版本和审计收据。未知结果只能重试相同 UUID/完整请求，表选择和金额锁定；撤权或表删除后不能用历史收据绕过当前校验。无新迁移、权限或主库门禁变更。
