# 当前配送选择与整车库存

2026-10-28：`cart.ReadSelectedManualShipping`在持有者/版本锁内重新执行当前分组和手工固定运价读取。输入只有配送选项ID及可信服务器provider注册名单，不接受分组、仓库或金额。每个当前需要配送的profile必须且只能匹配一个有效报价；重复、额外、不存在、当前不合格或缺少选项均拒绝。输出保留当前报价及分组行，仍仅内部使用。

从每个所选报价读取当前渠道/set/provider关联仓库，为各配送行形成仓库限制，然后读取当前有效目录配置，统一执行`ReadCartStockAtLocations`。多个配送分组的行共用容量，不再逐组独立声称有货；不允许已失效provider仓库关系或浏览器自行指定仓库。保存的非配送标记沿用已有刷新语义：无变体的手工非配送行不产生库存需求；有变体且管理库存的非配送行仍参与渠道范围的共享库存；无库存管理的非配送行不需要仓库。
