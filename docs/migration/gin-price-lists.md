# 价目表基本设置与生效时间

来源为已安装 Medusa Dashboard 的 `price-lists/price-list-edit/components/price-list-edit-form/edit-price-list-form.tsx` 以及 `price-list-configuration/components/price-list-configuration-form/price-list-configuration-form.tsx`：标题和说明必填，状态为 active/draft、类型为 sale/override，开始/结束时间允许清空。配置来源会保留其他规则；本次只编辑基本字段和时间，不修改客户组/其他规则或表内价格。

Gin 新增受 price.read 保护的 `/api/admin/price-lists` 分页读取及 `/:list_id` 详情，POST 另需当前 price.write。只读取未软删价目表；详情带规则、价格数量、写入开关和完整版本。写入沿用默认关闭的全局价格门禁及互斥锁，校验完整版本、账号和 UUID 请求绑定。命令仅更新标题、说明、状态、类型及时间；现有 metadata、规则、价格与共享集合保持。0099只创建独立收据表，不赋权、不启用开关，未应用到主库。

请求八个字段必填，包含 operation_id/expected_revision；starts_at/ends_at 为 RFC3339 时间字符串或显式 null，保留至微秒，拒绝未知/重复键、类型错误及超过微秒的时间精度。标题最多4096 UTF-8字节、说明65536字节，请求73728字节。界面清空日期提交 null；未触及的时间使用服务器原字符串，防止日期控件丢掉已有微秒。控件与标签统一使用UTC。来源配置表单没有前后时间关系校验，本次不新增区间禁止逻辑。

Ant 新增价目表列表/详情抽屉，使用现有主题、Table/Form/Select/DatePicker/Drawer 和权限体系。清楚提示修改影响整张表的商品报价；规则在详情只读展示，记录数量不符时提示。读取失败可重试；保存结果未知时锁定字段并保留原UUID和完整请求，仅允许同操作重试。中文保存按钮提供明确可访问名称，避免自动字间距影响定位。
