设置 `CHECKOUT_PRODUCT_BROWSE=1`、`CHECKOUT_FRESH_CART=1` 后运行 `python retail/scripts/test-customer-orders-live.py --checkout`。真实 Astro/Gin/MySQL/Redis 联合通过 en/zh、390/1440 四组：创建响应 201、实际加购、购物车刷新、点击结账、支付先 pending 后 paid、唯一成单、刷新确认页和完成请求重放。未拦截业务 API。数据库复核四笔订单、四次支付创建、四次库存预留及通知意图，生产邮件队列隔离通道和重试恢复继续通过。前台 173 项单元测试全部通过。证据见 [报告](shopping-fresh-cart-joint-report.json)。

本次不操作旧数据库、真实客户或支付账户。临时容器和网络已清理。支付提供方和最终邮件 HTTP 仍为隔离替身；未证明真实扣款或外部收件。首页/列表进入、账号登录与订单归属、真实完整商品数据和客户物流仍需连续验收。购物车保持现有匿名能力模型，不把邮箱相同视作账号或历史订单归属。
