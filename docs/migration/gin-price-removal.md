# SKU 价格删除

新增私有 `POST /api/admin/products/:id/variants/:variant_id/prices/:price_id/remove`，沿用现有价格列表及独立 `price.write` 权限、0062 默认关闭开关、统一价格配置锁及收据表；无需新迁移。请求仅接受字符串 `operation_id` / `expected_revision`，拒绝未知/重复键、null、尾随内容和查询覆盖。

来源为已安装 Medusa 2.21.2 pricing module 的 `updatePriceSets_` 与 `removePrices_`：从价格集合移除目标价格；共享集合的多个 SKU 共同受影响，集合及 SKU 关联继续保留。来源调用 `priceService_.delete` 物理删除并级联规则。新实现遵循项目保留 ID/软删除约束，改为在同一事务中标记价格和活动规则的 deleted_at，保留精确 scalar/raw、原价目表与共享集合，不提供恢复入口。报价查询排除这些记录，删除地区价可回退基础价，删除最后可用价格后无报价。

命令先检查当前账号及产品/价格读写权限、运行开关、当前产品/SKU/价格集合关联，再读取收据；已删除价格也能通过保留行恢复同 UUID 的成功结果，但撤权/删除关联后不可恢复。共享收据中将 action=remove 纳入规范请求绑定，创建或金额编辑 UUID 不能被重用来删除。新操作要求当前完整价格修订，覆盖规则、价目表、共享成员与全局版本；删除、规则软删、全局版本增加及含原精确金额/规则的审计一起提交。开关关闭时包括成功重试也拒绝，与现有价格金额命令一致。

Ant 列表增加“删除价格”操作及确认抽屉，显示金额、币种、数量限制、价目表及共享 SKU 数量。结果未知时保留原 UUID/版本，仅允许重试同一命令；明确冲突/拒绝后提示关闭重读。表单使用现有 Ant 组件和危险操作状态，没有更改商店样式。
