# 私有完成结账接口与前台传输

2026-10-30，C06。`POST /api/store/carts/:id/complete` 已接入经过验证的本地完整成单事务。请求只允许空 JSON 对象，不接收版本、支付状态、金额、远端支付ID、订单ID或重定向地址。服务器从当前拥有权对应的冻结尝试解析操作与输入版本，再在成单事务中重新校验当前凭证、冻结 paid 证据与收据。

接口需要当前 Redis 购物车 possession、同源 Origin 和 CSRF，按独立 completion-possession 键限流，不延长凭证或设置新cookie。URL购物车ID必须匹配凭证；变更代际、停用拥有权、撤销 Redis 凭证和关闭运行能力均拒绝重试。已关闭的购物车仍可通过当前有效凭证返回原成单收据，避免丢响应后因草稿已关闭而无法恢复。响应只含 cart_id、order_id、version，禁止缓存，包括路由前的413拒绝。

Astro 的固定路径私有桥已支持 complete；`CartClient.complete` 发送空意图，严格解析绑定购物车的收据，保留大整数版本。网络失败、依赖错误或不可解析成功响应均保留不确定状态，不能推断未付款或再次扣款。桥仅转发限定购物车凭证/CSRF，不传后台或客户账号凭证，不接受查询参数或外站路径。

本批连接到前台传输层，尚未修改付款结果页去调用完成接口，也未增加订单确认详情页。首次付款按钮和运行支付渠道配置、客户订单归属、真实发信及沙箱联合验收仍缺，不代表前台交易闭环已经完成。

## 验证

HTTP用例验证首次成功提交、未paid拒绝、成单末尾异常503后同一空意图重试、购物车关闭后原收据恢复、权限撤销、CSRF/Origin/参数注入拒绝、严格空JSON、413禁缓存、无私有支付字段/邮箱/地址和无cookie续期。后台原订单读取、账目、库存和促销成单回归同时通过。

前台119个测试通过，包含新完成传输与私有桥用例；Astro检查286文件零错误、零警告。本批没有改变页面样式，未执行浏览器联合成单或真实渠道验收。SQL/HTTP证据见 [运行报告](cart-order-snapshot-runtime-report.json) 的 completion_http，附参与源码哈希。
