# Astro 原结账付款及复核步骤

配送完整且没有未决请求时，原“继续付款”按钮进入 `?step=payment`。页面读取 Gin 私有 `payment-options`，仅展示服务端当前可用方式。此次接 hosted Mollie；地区没有可用方式时显示原无支付方式提示并禁用继续按钮，不把 PayPal/卡入口伪装为已可用。

沿用原结账外壳、进度条、CSS、支付标题/Headless UI Radio、复核说明、订单摘要和中英文案。点击“Review and pay/核对并支付”使用已保存操作发起付款，成功后进入 `?step=review`，再次私有读取冻结后的联系资料和金额/商品/运费，所有版本须一致且等于创建响应版本；复核摘要不保留创建前旧金额。“立即付款”只跳转经过 CartClient 校验的服务端付款链接，不在浏览器认定支付成功。

超时或丢响应保留原操作；刷新重新加载原购物车并恢复同一笔操作和冻结前版本，既不更换编号也不再次创建付款。已冻结时不再调用需要写锁的可变配送报价读取。processing/requires_review 显示等待/审核提示和现有付款结果页入口，不显示成功。复核中编辑支付步骤可回到已有方式，再次继续不会新发起付款。其他页/浏览器已冻结但没有本机记录时可查看结果，不猜测新操作。未决本地记录不会授权任何后端行为。

只有 Gin 返回经当前凭证授权的成单结果后，结果页才清理同购物车且结构有效的付款记录；其他购物车记录不删除，存储失败不改变真实成单结果。不得以URL、浏览器记录或跳转成功替代付款核实。
