# SKU 地区价格录入

承接原Dashboard pricing-edit按地区/币种录入、产品价格rules.region_id模型。扩展现有基础价格创建接口，增加可选region_id；省略时原基础价格行为及请求JSON不变。无需DDL，沿用0062默认关闭开关、独立price.write、统一价格命令锁和审计收据，主86未升级/启用。

GET price-creation增加真实未删除地区及币种、已有纯地区价格配置；地区配置参与预期版本。Ant沿用现有价格抽屉，地区选择自动带入币种，限制只能使用该地区币种，已有地区价格不能重复新增；原基础币种禁用逻辑仅用于未选择地区时。共享集合提示保持，不隐式复制集合。失败或未知结果以原UUID、地区、币种、金额重试。

服务端对地区与有效币种关系重新校验，不依赖客户端禁用；价格、region_id/eq规则、rules_count=1、全局修订和收据同事务提交。地区未知/软删/币种不匹配拒绝。仅无价目表、无数量限制且只有一条地区eq规则的既有价格阻止重复新增，不吞掉其他条件记录。读取沿用现有pricing.Read，指定地区匹配时优先地区价，其他地区回退基础价。金额和raw_amount保持完整字符串精度，不引入浮点转换。
