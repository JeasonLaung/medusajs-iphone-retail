# 正式账户导航与资料概览（局部交付）

承接原 `modules/account/templates/account-layout.tsx`、`components/account-nav/index.tsx` 和 `components/overview/index.tsx`，正式 Astro 账户根页、资料及地址页恢复原桌面240px侧栏、移动账户菜单与子页返回账户入口。五个原入口、退出、选中态、中英文字、原SVG及Ant Menu沿用；移除临时双链接和底部退出按钮。资料和地址的既有编辑器、页尾帮助入口保持原行为。仅用原 Ant 组件，没有改主题或全站样式。

概览读取当前 Gin customer 会话及其地址接口；资料完成度沿用原四项规则：邮箱、完整姓名、电话、默认账单地址，每项25%。地址数量来自当前客户真实响应，不使用历史导入地址或邮箱匹配。地址加载期间不显示0，失败隐藏统计并显示显式重试；请求代次与卸载检查防止晚到结果覆盖新状态，成功写入继续触发客户重新查询。退出在请求期间禁用菜单动作，成功返回登录并继续触发原跨标签页通知。

近期订单仍显示不可用提示，没有将接口未接通伪装为“没有订单”。订单和回收菜单恢复原URL，但对应页面与业务接口仍待迁移，本批不能据此验收导航全链路或完整账户dashboard。邮箱修改仍未实现；不通过同邮箱让新账号继承旧记录。真实账户→交易→订单/回收→售后联合路径仍是本期必做范围。
