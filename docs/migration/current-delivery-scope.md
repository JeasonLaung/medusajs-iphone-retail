## 支付与回收的准确含义

购物支付承接当前实际使用的 PayPal、PayPal Card、Mollie 入口及返回/通知/退款依赖。先把前台可操作流程和后台订单打通，再围绕需要的付款安全与故障恢复补齐；不能只持续建设未接到页面的适配器，也不能用手工标记已付替代在线支付。

原回收 `mark_paid` 是管理员在客户接受终价后记录 payment_reference；并没有自动向客户转账的API。第一阶段承接这条真实业务闭环，不能凭“包括支付”新增银行代付系统或声称人工记录已经完成转账。终价拒绝/申请退回、重拍、私有照片和回收设备关联都属于现有前台的完成条件。来源详见 [回收与邮件](buyback-and-mail.md) 和 [设备命令](device-commands.md)。
