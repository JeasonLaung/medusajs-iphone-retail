# 回收价格历史数据导入

回收价格作为商品配置加入既有 `catalogimport`，其余回收申请、照片、设备关联和付款操作仍使用各自业务迁移策略，不会被本次配置导入顺带写入。生成计划同时绑定原商品映射、运营映射、159 表字段计划及完整值唯一性计划的 SHA。

`buyback_price` 的十个源字段按原样写入 `buyback_prices`；金额及 raw 金额需要精确一致，SQL NULL、JSON null、报价规则、时间和软删除信息保留。不能表示的金额拒绝导入，不截断、不四舍五入。商品外键及活动商品/容量唯一性保持启用，完整容量同时进入原完整值去重登记。

调用方持有事务和提交权；完整快照校验通过之后才能提交。相同快照、源行和目标行重放只校验，不覆盖已有目标；快照、源字段或目标漂移拒绝。该实现不连接源数据库，不创建或迁移旧登录账户，也不启动后台任务或调用支付渠道。

隔离回归从固定、Git 忽略的 v2 快照读取 61 条价格，这些真实记录均未软删除；软删除读取和唯一性边界沿用此前的人工 SQL 用例，不能由这 61 条记录单独证明。私有原实现对照程序直接调用原 TypeScript `assessmentPrice` 和容量规范化，生成四种问卷状态的估价及各商品价格列表；私有预期只在独占容器 tmpfs 内传递，不写入报告。全库导入回归同时覆盖原商品、库存、订单、支付、配送和税配置，核对整体回滚、原样重放及只读接口前后指纹。

本项只证明价格导入与接口读取，不能证明回收申请、照片、检测、报价确认、支付或退回已闭环。通用完整 v2 写入协调器尚未开放，原前台问卷页面尚待接入。

本次结果：61 条价格、28 组价格列表、244 次原函数估价一致；源/目标/快照漂移各 1 项拒绝，21,898 条配置回执原样重放，23,620 条业务行整体回滚，创建旧登录账户为 0。72 个正式迁移直接执行，未注入审阅 DDL；容器单核、768 MiB、无外网和端口发布，已核对所有权后清理。详细计数与源码 SHA 见 [实库报告](catalog-mysql-rehearsal-report.json)。Go 全量、生成计划和原报价夹具检查通过，旧 health/app/sell 均返回 200。
