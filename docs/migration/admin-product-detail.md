# 后台商品详情、关系与变体查询

2026-10-28。`internal/catalog/admin_detail.go` 替换后台旧详情 payload 解码及
ID/handle 模糊 OR 查询，使用完整审查版关系字段。GET `/api/admin/products/{id}`
仅按原 ID 查未删除商品，返回基本九字段、副标题、描述、实际图片和商品选项值。
GET `/api/admin/products/{id}/variants` 独立分页，默认20/最多100，offset上限100000；
按 variant_rank（NULL在后）与ID稳定排序。SKU始终字符串，配置值、库存管理和
缺货订购开关为明确字段，不返回原metadata/payload、价目/库存推测或条码内部字段。

商品详情与变体分别使用只读REPEATABLE READ事务，不声称两个请求是同一快照。
选项须有未删商品成员关系，值须有未删成员关系且所属option吻合。共享选项的
其他商品值不混入；变体有未知/已删/跨商品值或同一option多个值时，保持变体
记录与未归属value ID并标记配置不完整，不捏造值，不将该标记当作库存或购买授权。
商品图片按rank/ID排序，变体图片还须有未删关联且属于同一商品。

关系读取有显式上限：每商品1000选项、10000值、1000图片；每页变体最多10000项
选择/图片关联。超限返回固定503，不静默截断后宣称完整。详情不接受额外query；
变体只接受limit/offset，未知/重复/非法参数400。不存在和软删除均404，数据库或
旧结构不兼容503；没有payload兼容fallback，旧0001数据库不能运行此详情。

React `/products/:id` 按需加载；列表标题为可访问链接，刷新深链有效。Ant
