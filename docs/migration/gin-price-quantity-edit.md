# 已有价格数量条件编辑

新增 `POST /api/admin/products/:id/variants/:variant_id/prices/:price_id/quantity`，与原金额编辑使用独立动作收据。请求必含 operation_id、expected_revision、min_quantity、max_quantity；数量为最多20位正整数字符串或显式 null，两端存在时最小值不超过最大值。null 清除对应限制，缺字段、空字符串、数值JSON、重复键和未知字段拒绝。沿用已安装来源数量价格表单的正整数/可空边界，保留原报价选择规则，不新增区间重叠禁令。

命令沿用默认关闭的价格写入开关、当前 product.read/price.read/price.write、全局价格锁和完整版本校验。同 UUID 绑定动作、账号、路径及完整请求；重试前再次检查当前权限、商品/SKU/价格及共享集合关联。事务只更新该价格的 scalar/raw 数量边界和更新时间，并写入全局版本及前后快照收据；价格ID、精确金额、币种、价目表、规则及共享集合保持。清除同时将 scalar/raw 设为 SQL NULL，末尾收据失败整体回滚。

Ant 现有价格行增加中英“编辑数量条件”，保留原金额编辑/删除操作和主题。读取精确有效数量，留空表示清除；保存结果未知时锁定两项输入并仅允许原 UUID 和完整请求重试。共享价格集合继续显示影响提示。
