# 新账号动作权限运行时

2026-10-28。`0023_authorization_actions.sql` 和 `internal/authorization` 将已有 Gin 私有业务接口从仅校验账号身份推进到持久动作权限。0023 建立 9 项全店动作；0024 扩展至 11 项并接入[角色授权管理](authorization-management.md)。仓库范围或供应商范围尚未验收。

## 数据与初始化

六张独立表保存运行模型/修订、精确动作字典、主体类别、启用角色、角色动作及账号角色成员关系。没有数据库级默认全权限、旧账号映射或从 admin_users.role 自动生成成员关系。动作名精确且区分大小写，SQL CHECK 和运行词表拒绝未知值及通配符；多角色动作取并集，请求中要求的动作必须全部满足。

`create-admin` 在同一事务中创建新账号、显式 employee 主体、独立 Administrator 角色、当前十一项动作、成员关系及 `authorization.bootstrap` 审计，并更新权限修订。任何失败全部回滚；已有主体不能被 Bootstrap 重置或追加隐式授权。它只授予当前明确字典，未来新增动作不会因角色名称自动获得。Bootstrap/CheckTx 拒绝非事务调用，API 启动和健康检查验证编译模型及完整动作字典。

原先在 0023 之前手动创建且没有新主体/角色授权的账号仍可认证，但业务权限为空；不能为了兼容自动授予其全店权限。旧登录账号、密码、会话、旧角色成员与个人 grant 均不导入。

## 当前路由动作

| 路由 | 必须具备的动作 |
| --- | --- |
| 商品列表、详情、SKU 列表 | product.read |
| 修改商品基础字段 | product.write |
| 配置价格 | product.read + price.read |
| SKU 库存明细 | product.read + inventory.read |
| 修改库存与在途量 | inventory.read + inventory.stock.write |
| 订单列表与成交行详情 | order.read |
| 订单金额 | order.read + order.amount.read |
| 订单支付明细 | order.read + order.payment.read |
| 订单履约明细及地址 | order.read + order.fulfillment.read |

认证、会话、Origin 和写操作 CSRF 先执行，动作检查通过才进入业务处理器。GET `/api/admin/auth/permissions` 返回当前 revision（精确字符串）、scope 和动作数组；未知查询参数 400、匿名 401、权限不足 403、依赖或模型异常 503，使用私有 no-store 响应。账号、退出和权限快照不要求业务权限，以便无权限账号仍能查看自己并退出。

主体为空时 scope=none；warehouse/supplier 主体即使分到相同动作，也不获得上述全店接口，动作快照为空。身份层目前仍只接受新 admin 类型账号，后续仓库/供应商登录及对象/字段范围另行实现。这里没有把有动作视为拥有全部仓库、历史订单或供应商来源。

## 事务与撤权

普通请求每次从当前 SQL 获取启用账号、主体、成员关系、启用角色及动作；不缓存到长期 JWT 或 Redis grant，不相信浏览器送来的动作。后台 snapshot 使用只读 Repeatable Read 事务保持一次查询一致性。

商品基础编辑和库存编辑在真正的业务事务、业务行锁和幂等回执读取之前调用 CheckTx。它按运行模型 → 当前账号 → 主体 → 成员/角色/动作取得 SHARE 当前读锁，保持至提交/回滚；旧 RR 快照无法保留已撤销权限。账号启用/密码/身份/认证代数重查沿用原会话规则。权限变更必须按同一顺序先锁运行行 FOR UPDATE、修改授权行及增加修订；新账号初始化及 0024 的角色/成员变更命令遵守该协议，详细审计、修订及 Ant 页面见角色授权管理说明。

幂等返回同样重查当前动作；撤权后不能借旧 operation_id 获得先前成功结果。运行行锁将遵守协议的权限变更与进行中的命令串行化；并非声称已经完成所有权限修改入口或所有业务命令。读请求在授权检查后仍可能与撤权并发，尚未保证对已开始响应的即时撤回。

## Ant 页面

新增权限 Provider 从同一快照获取菜单、路由和按钮权限；首读加载、失败关闭、明确重试、401 会话结束。页面可见时每 30 秒、窗口聚焦和恢复可见时重新读取；依赖失败清空上次动作，不继续展示授权按钮。商品编辑/价格/库存、库存编辑按钮及订单金额/支付/履约区域分别按动作控制。直接访问无权路由显示 Ant Result 403。交互控制不替代 API 授权，浏览器不持久化 grant 或修订。
