# SKU 已有配置价格金额编辑

本批补齐商品运营中的已有价格记录写入。React 商品详情→SKU「查看价格」→「修改金额」，继续使用 Ant Drawer、Form、Input、Descriptions、Alert 和原有表格。前台页面与样式保持不变。

来源沿用已有 `pricing_prices` / `pricing_price_rules` / `pricing_price_lists` 和 `catalog_variant_price_sets` 关系，报价使用同一个 Gin pricing.Read 引擎。已有读取及原业务规则详见 [配置价格](admin-variant-prices.md)、[前台商品](store-products.md) 和 [当前交付范围](current-delivery-scope.md)。本命令只修改选中价格记录的金额及其 raw_amount BigNumber 镜像；不重建价格集合，不覆盖地区、阶梯数量、币种或价目表规则。

## 接口与权限

- GET `/api/admin/products/:id/variants/:variant_id/prices/:price_id` 返回当前编辑上下文、有效原始金额、共享SKU数量、修订及开关。
- POST 同一路径，严格三个字符串字段 `operation_id`、`expected_revision`、`amount`；拒绝重复/未知字段、null、数字金额、尾随JSON、非法UTF-8、查询参数及超过2048字节的正文。
- 读取要求当前 `product.read`、`price.read`；写入还要求新增的 `price.write`，事务内重新核对。仓库或供应商主体不能调用；商品基本编辑权限不能推导出价格写权限。新增权限不自动授予已有角色。
- 0062迁移增加独立命令开关与审计收据；`catalog_price_edit_runtime.enabled` 默认FALSE。显式迁移并启用后才可提交，通用目录写开关仍保持原约束。测试仅在自己创建的隔离数据库启用。

金额通过字符串保存为规范DECIMAL(38,18)，非负、最多20位整数和18位小数。零价有效，空值不代表零价。界面不用浮点或币种倍乘，输入按字符串补足18位小数；拒绝指数、超精度及负数。编辑表单显示原 raw_amount 的有效金额，使用报价引擎同一精度解析器，不能用已舍入的数据库标量覆盖原有效值。保存同时更新标量和 `{value,precision:20}`，报价不会继续读取旧raw值。

## 一致性与影响

价格集合仍可被多个SKU共用，表单明确提示影响数量；不会复制集合将其伪装成独立价格。商品→变体→集合→价格的当前有效关系先于收据恢复校验；删除或解除关联后原路径不能重放。修订含完整价格、raw值、规则、价目表、共享成员及全局命令修订。后续价格/规则/集合关系写入需共用同一命令锁。

授权→命令锁→当前关系/配置→同操作收据→修订检查→标量/raw金额→全局修订→审计与收据，在同一MySQL事务中提交。收据绑定账号、商品、变体、价格和完整请求；并发同操作只有一次新修改。迟到的收据写入失败会撤销所有修改。界面丢响应时锁定原提交内容，以同一操作重试；409后要求关闭并重读。审计保留前后公开价格上下文及原raw金额，不向HTTP返回raw JSON。

公开商品报价读取提交后的同一价格数据；已有付款和订单快照不被该配置命令改写。本批未新增价格、删价、改变价格条件或完成完整SKU创建；这些仍属于商品运营清单，不能因金额编辑通过而将C03或全站闭环标为完成。

## 验证范围

隔离MySQL/Redis验证默认关闭、独立授权、完整38位十进制、原始精度优先、零价、四并发一次提交、请求与变体绑定、规则变化后的过期修订、规则保留、末尾失败全回滚、撤权/仓库主体/解除关联后的重放拒绝。用真实公开商品handler核对两个共享SKU修改后的零价、完整精度金额及地区规则报价。

`python retail/scripts/test-warehouse-inventory-joint.py --price-edit` 启动拥有归属标签的独立数据库、Redis和正式Gin二进制。浏览器真实登录→商品SKU价格表→共享提示→非法金额校验→保存→公开报价API核对→刷新另一SKU读取→中英及390宽度。回查持久金额/raw值、一份审计和两条共享关系，清理归属容器、网络和临时二进制后才生成报告。该用例验证React和公开Gin报价API，不声明已经完成整条Astro购买流程。

新增后台浏览器回归覆盖原raw精度显示、丢响应后同一请求、字段锁定、409停止盲重试及撤销价格写权限后的只读表格。证据见 `price-amount-edit-report.json` 与 `price-edit-joint-report.json`。旧开发服务继续保持可访问，未操作服务器或真实业务数据。

后续已补 [SKU新增基础价格](gin-price-create.md)，复用本命令锁、开关和操作ID收据。原金额编辑的证据范围保持不变。
