# 历史私有回收图片复制

2026-10-30。核对已安装 Medusa 2.21.2 本地文件 provider 的 upload/getAsBuffer：原回收上传生成 private-时间-buyback-UUID.扩展名，文件模块返回键作为 ID，内容位于配置的 `.private-files`。源系统仍运行，迁移不得删除源文件。

`ReadLegacyPhoto` 使用显式 `os.Root`、单层原文件名规则、普通文件/3MiB 上限及原 JPEG/PNG/WebP 签名读取，拒绝绝对路径、父目录、URL 和嵌套路径；没有文件写入或删除。`ImportLegacyPhotoTx` 接收调用方已核验快照的文件键、SHA256 和字节，锁申请与照片，核对既有元数据、MIME 和导入账本来源；私有 DB 字节及新 0079 复制证据同事务保存。保留原 storage_key、审核、时间与申请记录，因此元数据导入精确重放仍可验证。

同源同字节重放核对实际持久字节；错快照/键/哈希/损坏字节拒绝。已过期照片禁止复制，清理后禁止复活。原私有读取仅在复制证据键/MIME/摘要和实际 DB 字节全部一致时承认旧键，不开放任意旧路径读取。180天任务可清理已复制的旧照片 DB 字节及过期元数据；未复制的旧键继续保留计数，源文件始终保留。新旧账号和历史资料归属权限不变化。

验证：人工隔离 MySQL 回收联合夹具验证复制/重放、元数据原样重放、证据不匹配、存储字节损坏、无新客户读取权限、已复制照片到期清理与禁止复活；复制证据写入故障验证回滚恢复无字节状态。本机六个实际私有文件只读经过受限读取器，读取前后字节 SHA256 一致。Go 全量及原回收浏览器联合流程回归。

本批提供文件读取/事务复制能力，没有对真实目标库执行导入。全量快照/文件清单协调、真实历史申请和照片联合演练、历史后台入口及通知邮箱整体验收仍待完成。源文件删除不在此阶段操作。
