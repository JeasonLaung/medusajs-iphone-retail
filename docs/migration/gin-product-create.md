# 新商品与初始选项创建

2026-10-31：React Admin 商品列表新增 Ant Design 创建抽屉，Gin 提供 `GET /api/admin/products/creation` 和 `POST /api/admin/products`。沿用当前独立员工认证、Origin/CSRF 防护、`product.read` / `product.write` 权限及商品目录模型，不调用 Medusa。

创建包含标题、链接标识、说明、状态、销售渠道、配送配置、可选合集/类型/分类、图片 URL 和初始选项组。先创建商品，再复用现有 SKU、基础价格和库存流程。图片 URL 按顺序保存，首张作为缩略图；本增量没有文件上传或已有商品图片/选项编辑功能。

显式迁移 `0088_catalog_product_creation.sql` 只增加默认关闭的 `product.create` 独立开关。不开启目录通用写入，不在启动时建表。关联配置必须存在且可用；商品、渠道/配送/分类关系、图片、选项与值、选项成员关系及不可变操作收据在同一 MySQL 事务写入。商品创建不产生 SKU、库存数量、支付或邮件。

请求采用完整字段、有限长度和严格 JSON 解码，拒绝重复/未知字段、必填 null、重复选项/值及不安全图片协议。操作 UUID 与员工、完整请求绑定；同请求并发只创建一次，变更重放及重复活动 handle 返回冲突。收据重放仍检查当前权限，创建开关关闭后允许已完成操作恢复回执。复用现有商品编辑收据表，不额外制造另一套审计存储。

- 真实 React Admin → Gin → MySQL/Redis 浏览器：创建商品和两个初始选项值、新建 ERP SKU、添加精确基础价格 `129.123456789012345678`、刷新保留；公开商品接口核对同一 SKU 和金额，没有 API 拦截或替身。
- 真实 Astro → Gin：已发布商品页显示同一数据和精确金额属性；零库存明确缺货且无法购买；中英文和 390px 布局通过，浏览器脚本错误 0。
