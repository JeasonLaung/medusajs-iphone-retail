# Astro 加购客户端与真实浏览器

2026-10-28。继承现有 `CartClient` 私有同源传输，新加 `addItem(cartID, {operationID,version,variantID,quantity}, {csrfToken})`。UUIDv4、版本和数量为规范字符串；只发送三个服务端命令字段，不允许价格/店铺/身份透传。使用明确传入的购物车CSRF，新增 `cartCSRFFromCookies` 只读取当前HTTP/HTTPS域的可读cookie，不读取持有凭证，不将scope CSRF混用。

成功回执按固定字段校验；返回cart必须相同，版本精确等于请求版本加一，合并数量不小于本次加购量且不超过十亿。版本经BigInt校验，不转Number。回执是原操作结果，不能替代当前购物车；后续新操作需读取最新状态。HTTP 422在本命令标为item错误，建车仍为region错误；客户端不读取任意错误正文，暂不细分库存/缺价，页面可复用原通用失败提示，不能把所有item错误都称为缺货。

网络/服务依赖/响应损坏仍可能已经提交，保留原操作键、版本和命令重放；客户端不自动重试、不自动创建新购物车，也不续持有凭证。生产items/checkout能力仍false。
