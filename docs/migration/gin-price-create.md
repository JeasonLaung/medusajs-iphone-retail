# SKU 新增基础价格

本批在现有商品→SKU→价格抽屉接入「新增基础价格」，使用Ant Form、Select和字符串金额输入。承接原价格集合/价格规则模型及报价引擎，前台页面和交互不改版。商品/SKU本身创建、完整价格规则管理和全站交易仍需继续。

## 行为

新建价格固定为所选币种、无地区/阶梯数量/价目表限制的基础价。币种从当前未删除的真实币种配置中选择，客户端不能指定价格集合ID、价格ID或规则。金额保持非负DECIMAL(38,18)字符串与raw_amount镜像同步，零价可用。

当前SKU没有有效价格集合时，同一事务新建集合、关联与价格；仅有一个集合时沿用，多个有效集合时拒绝并要求核对配置。共享集合仍然共享，界面提示影响SKU数量，不隐式复制。已有同币种、无数量上下限/价目表/有效规则的基础价格时拒绝新增，并在币种选项中禁用；应使用已有金额编辑。地区/阶梯价格保留，不因新增基础价而删除。

## 接口与一致性

- GET `/api/admin/products/:id/variants/:variant_id/price-creation` 读取可选币种、已有基础价币种、当前集合/共享数量、开关及摘要。
- POST `/api/admin/products/:id/variants/:variant_id/prices` 创建价格，严格接收四个字符串：operation_id、expected_revision、currency_code、amount。拒绝未知/重复键、null、数字金额、附加JSON、查询参数、非法UTF-8或超过2048字节正文。
- 沿用当前product.read、price.read与独立price.write权限；事务中核对当前账号和权限。warehouse/supplier不能调用。沿用0062命令开关与锁，无新增DDL，默认不开启写入。

事务顺序为授权→统一价格命令锁→当前商品/SKU关系及配置→相同操作收据→摘要→校验币种/重复基础价→必要集合与关联→精确价格→全局修订→审计收据。收据与已有金额修改共用操作ID命名空间，完整请求不同不能重用；绑定账号、商品和SKU，成功重试返回原创建ID。重放仍要求创建价格当前通过该SKU关联可达，解除关系或撤销权限后拒绝。末尾失败回滚集合、关联、价格、修订与审计。

摘要包含当前SKU、有效集合、全部价格/规则、共享成员、币种配置及全局价格修订。打开后配置改变返回409。丢响应后Ant表单锁住原币种/金额，保留原UUID请求重试，不因重试生成第二条价格。

## 验证与仍缺

隔离SQL/HTTP验证：默认关闭；新集合/关联/价格事务；收据末尾失败完整回滚；四并发同操作只建一条且ID一致；同币种基础价重复拒绝；未知币种拒绝；精确报价与共享集合新增另一币种零价；原有地区/基础价格保留；跨SKU请求重用、解除关联、撤权与仓库主体重放拒绝。

真实浏览器联合 `python retail/scripts/test-warehouse-inventory-joint.py --price-create`：新账号登录，原无价格SKU→新增基础价→选币种与精确金额→保存并回读→公开商品报价API→刷新保持→已有基础币种禁用→中英/390宽度；独立MySQL回查raw与标量、一条SKU关联及一份审计，清理自有容器/网络/二进制后才生成报告。浏览器API没有mock；验证公开Gin报价，不将其扩大成完整Astro购买链已通过。

后台合成API浏览器另验零价、丢响应同UUID/币种/金额重试、控件锁定及撤销写权限后的只读。证据为 price-create-report.json、price-create-joint-report.json。

新增地区/数量/价目表条件、删除价格和完整商品/SKU创建仍未完成，继续属于本期商品运营的待办；完整前台闭环保持未验收。
