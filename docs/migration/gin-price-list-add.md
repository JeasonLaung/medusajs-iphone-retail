# 已有价目表多商品批量添加价格

来源 `price-list-prices-add-form.tsx` 是“选择商品→录入价格”两步，调用 `useBatchPriceListPrices` 的 `create` 参数。目标复用已验证创建向导的后两步，保留搜索/分页/跨搜索选中记录、原SKU及自动ERP身份、地区/币种/数量表单和共享集合提示。此处只添加新条件，不改变表的标题、说明、状态、时间、元数据、规则或已有价格；来源更新/删除/批量替换另行验收。

新增 `GET /api/admin/price-lists/:list_id/price-addition?product_id=...`、`POST /api/admin/price-lists/:list_id/prices`。严格四字段命令：operation_id、expected_revision、product_ids、prices，嵌套价格也逐键检查，拒绝重复键/未知字段/null或错误类型；精确金额和可空数量仍为字符串。上下文将目标表当前版本与所选商品/SKU/价格集合版本绑定。限制与原创建一致：20商品/500SKU/200价格，超限拒绝而不截断。

事务沿用私有认证、Origin/CSRF、product.read、price.read/write、默认关闭价格门禁及全局价格锁；0099收据以action=add-prices隔离其他动作，无新DDL/权限。批量添加与创建共享价格校验/插入函数，保留共享集合和精确raw金额、数量、地区规则。若任一条重复、非法或末尾收据失败，整批回滚；同UUID并发只能有一次新写入。未知结果锁定完整表单并以原命令恢复，当前权限/门禁、未删除表及所选商品/SKU仍校验。
