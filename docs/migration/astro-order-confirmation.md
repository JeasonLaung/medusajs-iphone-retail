# Astro订单确认页与成功跳转

2026-10-30，C06。恢复原 `/{countryCode}/order/{id}/confirmed` 路径，结果页只在服务器返回已提交订单收据后构造本站确认链接并跳转，订单ID来自已授权收据；不接受渠道URL中的订单或成功参数。

确认模板按原完成模板的区块/类名和现有Ant组件迁移：感谢/下单成功、日期与原19位编号、商品图片/选项/数量/价格、汇总、配送地址/联系/方式、付款金额/时间及售后区域；使用现有全站Header/Footer、1200px布局、Outfit/DM Sans、原Tailwind编译样式与主题。保持原商品价语义，以含税折后行总额除以数量显示单价，并保留优惠前划线价。小数按货币位数使用BigInt有理数四舍五入，不把精确金额转成浮点数。

`CartClient.confirmation` 经固定私有桥读取Gin确认接口，严格核对订单身份、行/商品对应关系、唯一行、精确金额/币种、地址字段和日期，拒绝未知私有字段或混合其他订单数据。只明确401/404映射为不可访问；依赖错误保留错误状态并提供重试。页面为client-only私有加载，SSR只含页面外壳及路由ID，不将地址、邮箱或订单金额写入HTML/island props。页面与接口private/no-store、no-referrer/noindex，不转发后台/客户账号凭证。

本批仍有明确暂缺：邮件实际发送未接，所以未显示原“邮件已经发送”文案；售后业务未迁移，原区域保留但操作禁用并展示不可用，不模拟成功；履约追踪尚待配货/发货流程。客户长期订单归属、首次付款按钮、优惠提交、真实渠道配置/沙箱和通知worker尚待完成。因此已完成确认展示与成功跳转，不代表整个购物/售后闭环完成。
