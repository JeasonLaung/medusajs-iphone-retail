# 变体价格配置查询

2026-10-28。Gin 新增 GET `/api/admin/products/{id}/variants/{variant_id}/prices`，
React 商品变体表提供 Ant Design Button、Drawer、Table、Descriptions、Tag、Alert。
显示关联价格集合、币种、金额、阶梯数量、逐条规则、价目表状态/类型/时间及规则；
中英文、分页、空态、失败重试和 401 回登录均沿用后台约定。

这是已配置价格的运营查询；尚未实现完整结算选价、税务及价格编辑。
界面明确提示成交金额仍需地区、数量、客户、时间和税务上下文，不取最低配置价代替。
未知条件保持原属性、运算符和值供核对，不推断适用性。

读取采用只读 REPEATABLE READ 事务，先核对未删商品及其未删变体，再取未删关联与
未删价格集合中的未删价格。保留共享集合关系，不复制或按名称拼接。
记录含已删价目表引用时保留 price_list_id，但列表详情为 null 并提示不可用；
草稿和未来生效价目表仍可在后台检查。规则过滤软删，记录计数与实际规则不一致时提示。
metadata、raw_amount、payload、价目表描述等未选择字段不进入响应。

金额和阶梯数量从 DECIMAL(38,18) 直接扫描为字符串，浏览器验证后仍为字符串，
仅用字符串去除无意义末尾零。零价、无价格与 NULL 上下限分别呈现，不经过 Number、
浮点换算或币种倍乘。JSON 条件值按原文本保留，长标识符不转为数字，也不注入 HTML。

仅接受 limit/offset，默认 20、最多 100、offset 不超过 100000；按币种、集合、价格 ID
稳定排序，计数和页数据在同一事务。每变体最多 1000 个集合，每页最多 10000 条价格规则、
10000 条价目表规则，超限固定 503，不返回截断后的完整假象。依赖失败也不返回空价格。
真实后台路由继续要求当前新员工会话，跨商品、未找到与软删除返回 404。

证据范围：

- [隔离 MySQL 报告](admin-auth-report.json)：人工 26 条配置验证完整 38 位金额、零价、
  NULL/小数数量、共享集合、软删过滤、未来/草稿/不可用价目表、未知条件、跨商品/匿名拒绝、
  实际 10000 条规则溢出时 503，以及读取前后业务指纹一致。
- [真实目录演练](catalog-mysql-rehearsal-report.json)：固定 v2 样本中全部 1558 个未删变体，
  1558 项价格成员逐条核对金额、币种、集合、上下限、价目表引用与规则数量；无写入。
  此样本价目表为空，不能代替人工价目表覆盖或全域验收。
- [真实浏览器](admin-live-report.json)：实际 Gin/MySQL/Redis，价格抽屉精度、规则、分页、
  中英三宽布局；[人工 HTTP UI](admin-ui-report.json)补充失败/恢复、空态、拒绝数字金额及文本安全。

库存、完整权限对象范围及 Astro 继续待办；不将 T020/T021/T023 标为完成。
