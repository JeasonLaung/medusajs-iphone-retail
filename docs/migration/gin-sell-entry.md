# Astro 回收入口和型号目录

`/{countryCode}/sell` 复用原 `sell-landing` 的结构、文案、图片和 CSS，保留开始回收、我的回收申请及两个折叠说明的交互和目标链接。国家、语言、页头和页脚使用既有 Gin 公开页面加载器；依赖失败返回 503，未配置国家返回 404。未连接 Medusa，也未增加登录身份数据。

型号目录加载器复用 Gin 公开商品投影，遍历全部商品页，保持原 iPhone 标题筛选、同名商品后值覆盖、去掉 `swappie-` 前缀、容量选项筛选及空白整理、GB/TB 排序、Air/SE/Pro/Plus/mini 顺序。不能只从回收价格表生成型号：原行为允许显示尚未配置报价的商品。沿用 Gin 目录稳定顺序；旧函数没有指定商品查询顺序，同名商品最终覆盖顺序仍取决于输入目录顺序。跨页重复商品、计数变化、超限和上游失败整体报错，不以部分目录充当成功结果。此加载器尚待问卷路由调用。

浏览器在中英文、390/768/1440 三种宽度及初始/展开两种状态下，与磁盘读取的原组件正文及原 CSS 比较，12 组截图像素一致，目标链接一致，无溢出或 hydration 错误。参考组件使用同一 Astro React/Ant Design 5 运行环境，对原 Ant Design 6 的 `iconPlacement`、Steps `content` 作对应属性桥接；这不是原 Next/Ant Design 6 全页截图验收。图片文件保持原字节，并已查看移动端截图。

型号算法测试直接执行原 TypeScript 函数，覆盖同名、非 iPhone、空 handle、Air/SE 及中英文容量；公开传输与异常分页测试通过。前端 159 项测试、Astro 343 文件检查通过（0 错误、0 警告、5 条既有提示），旧 health/app/sell 均为 200，最近旧服务日志未见错误。

问卷路由、暂存恢复、汇总表单、申请列表/详情、照片、检测、报价确认和付款退回尚待接入，入口按钮的目标 URL 仍保留原路径，但不能据此宣称这些目标页面可用。完整回收闭环继续待办。证据和源码 SHA 见 [报告](sell-entry-report.json)。
