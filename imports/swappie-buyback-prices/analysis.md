# Swappie 回收价格分析

来源：2026-10-22 抓取的 BE / EUR 数据。30 个型号，67 个型号容量组合，10720 条原始报价。

## 可复核的规律

- 每个型号容量有 5 种成色 × 32 种故障组合 = 160 条报价。SEALED_BOX 是未拆封，不映射到二手问卷。
- 抓取只请求了 256GB / 512GB / 1024GB / 2048GB；缺少 64GB / 128GB，不能据此当作已抓取价格。
- 拟合公式：无故障时直接取成色基价；有故障时 max(保底价, 成色基价 − 一次性故障费用 − 各故障维修扣款之和)。该公式复现 10720/10720 条（100%）；未解释的组合必须保留精确矩阵。
- 容量溢价和机型代际差异不统一，不能套固定每级加价。
- price.price、fixed_price、limit_price 是不同字段；目录以 price.price 为抓取参考，不把 fixed_price 或 limit_price 当正常收购价。

## 问卷映射（本项目策略，不是从接口证实的 Swappie 官网映射）

- 外观取屏幕、边框、背面中最差的非损坏等级：none → LIKE_NEW；minimal → ALMOST_NEW；some → GOOD；visible → MODERATE。
- 屏幕显示异常、裂痕、缺口、严重划痕统一为 BROKEN_SCREEN，只扣一次。
- 边框损坏或背玻璃损坏统一为 BROKEN_FRAME，只扣一次；损坏部件不重复参与外观降级。
- Face ID/Touch ID、前摄、顶部扬声器任一异常归为 BROKEN，只扣一次。问卷没有后摄问题，因此不会自动添加 BROKEN_BACK_CAMERA。
- 电池低于后台阈值时为 BATTERY_ISSUE；unknown 不伪装为电池正常，显示需检测确认。
- 无法正常开机或连接移动网络继续沿用不收购规则。
